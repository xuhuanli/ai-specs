# ai-specs：AI 辅助多端开发工作区

ai-specs 用于组织需求、技术方案、开发任务和验证资料，支持一名开发者借助 AI 完成多个端的项目开发。适用端和实现方式由实际项目决定，不绑定固定业务项目或开发者。

本文件说明工作区是什么、如何使用以及从哪里进入项目；[AGENTS.md](AGENTS.md)定义 AI 需要遵循的多端开发流程与文档约定。具体业务和工程规则由项目与代码仓库内的文档继续提供。

## 文档如何分层

| 位置 | 作用 |
| --- | --- |
| 根 README.md | 工作区说明、目录结构与使用方法 |
| 根 AGENTS.md | AI 通用工作流程、文档约定与 Git 操作边界 |
| [projects/README.md](projects/README.md) | 已接入项目索引，帮助定位目标项目 |
| `projects/<项目标识>/README.md` | 项目说明、适用端、需求资料和代码仓库入口 |
| `projects/<项目标识>/AGENTS.md` | 项目专属业务与跨端约定，指引下一步需要读取的文档 |
| 各端代码仓库及目标目录的规范 | 本端架构、实现、分支、提交和验证方式 |
| [docs/requirements/](docs/requirements/README.md) | 共用需求模板、示例与填写方法 |

AI 先理解通用流程，再进入目标项目，最后按任务进入对应端的代码仓库。项目文档可以继续链接版本索引、业务说明和专题规范，按本次需要读取。

## 目录结构

```text
ai-specs/
├── README.md                        工作区说明与用法
├── AGENTS.md                        多端开发工作流程与文档约定
├── .gitignore                       排除独立代码仓库
├── docs/requirements/               共用模板、示例与填写方法
└── projects/
    ├── README.md                    项目索引
    └── <项目标识>/
        ├── README.md                项目说明与资料入口
        ├── AGENTS.md                项目专属约定与阅读指引
        ├── prd/                     需求版本与配套文档
        ├── <项目专题文档>            按实际需要维护
        └── repos/
            ├── README.md            各端代码仓库入口
            └── <代码仓库>/           保留独立 Git 历史
```

具体项目的目录、仓库名称、业务规则与发布记录见[项目索引](projects/README.md)及其指向的项目文档。

## 怎么使用

1. **说明任务。** 提供目标项目、本次需求或问题、实际版本与适用端；上下文已经明确的信息无需重复提供。
2. **逐层读取规范。** AI 读取根 README 和 AGENTS，通过项目索引定位目标项目，读取其 README、AGENTS 和任务所需资料；修改代码前，再读取对应端仓库及目标目录的规范。
3. **按共同需求推进多端开发。** 核对本次适用端现状，确认业务规则、允许差异与验收标准，再按端维护方案、任务、实现和验证结果。角色可由同一人兼任，文档按实际需要裁剪。
4. **核对交付。** 分别记录各端完成范围、检查结果、未验证事项和各仓库提交、推送状态。需求变化时同步受影响文档。

可以这样发起任务：

```text
在 <项目标识> 中处理 <需求或问题>，需求版本是 <实际版本>，适用端是 <本次涉及端>。
请先按工作区入口读取项目文档及对应端规范，核对现状和范围，再推进需求整理、实现与必要验证。
```

未指定项目时，AI 会结合当前目录、上下文与项目索引判断；能唯一确定时直接进入，有影响操作的歧义时再确认。

## 文档与代码如何管理

共用方法和模板放在根目录，业务规则、跨端决定、版本资料和发布记录放在对应项目内。版本资料按 `projects/<项目标识>/prd/prd-vxxx-YYYYMMDD/<负责人>/` 组织，具体归档与使用方法见[模板说明](docs/requirements/README.md)和项目文档。

根 Git 仓库管理共用资料和项目协作文档，各端代码仓库保留独立的 Git 历史，由根忽略规则排除。文档与代码的提交、推送分别按用户已给出的授权执行，具体边界见 [AGENTS.md](AGENTS.md)。
