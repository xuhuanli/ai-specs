# CRM 版本需求索引

当前尚未确认需求版本，暂无版本目录。

确认实际版本后，按 `prd-vxxx-YYYYMMDD/<姓名>/` 建立资料目录；日期取该版本目录首次创建日，同一版本后续复用。当前用户目录名为 `sanshi`，只维护本人负责范围。

版本入口在本页登记，版本 README 索引负责人目录；需求、方案、任务及测试资料通过同一需求版本和 REQ、AC 编号关联。模板按实际适用端裁剪，见[共用模板说明](../../../docs/requirements/README.md)。

本目录由工作区根文档仓库记录本地历史，不上传远程。项目范围和接入状态见[CRM 项目说明](../README.md)。
