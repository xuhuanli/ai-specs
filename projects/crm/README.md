# CRM 多端协作

CRM 已建立独立项目目录，用于 iOS、Android 两个端的同步开发，未来可增加第三端。两个端的仓库地址已确认，所属部门和业务范围待确认。

工作区通用规则见[根 README](../../README.md)和[根 AGENTS.md](../../AGENTS.md)，CRM 项目规则见 [AGENTS.md](AGENTS.md)。

## 接入方式

1. 已确认平台为 iOS、Android，各端仓库地址见 [repos/README.md](repos/README.md)；所属部门及业务范围待确认。
2. 将各端现有仓库接入 `repos/` 下，保留仓库自身名称、Git 历史和远端。首次接入先读取各仓库现行规范、确认分支和未提交改动，再维护本项目的多端规范索引。
3. 确认本次需求实际版本及本人负责范围，在 `prd/prd-vxxx-YYYYMMDD/sanshi/` 下维护资料，并登记版本入口。
4. 对实际适用的两个端确认共同业务逻辑和验收口径，分别维护实现与验证结果。第三端确认接入后，再明确具体需求是否覆盖该端。

项目文档由工作区根文档 Git 仓库统一记录本地历史，代码由各端仓库独立管理。CRM 的账号、接口、业务决定、版本和发布信息以本项目确认资料为依据。

后续由一人开发两端，仅在开发当前需求、核对相关实现时，列出实际发现的逻辑差异、优化和对齐机会，不单独扫描寻找。默认记录两端现状、影响与建议，与用户讨论确认具体调整范围后再修改；其他已明确的需求工作继续推进。
