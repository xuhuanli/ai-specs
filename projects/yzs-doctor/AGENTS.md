# 云诊室医生端跨端协作约定

本文件适用于 `projects/yzs-doctor/`，只补充云诊室项目规则。工作流程、范围控制、归档、写作、验证和 Git 操作统一遵循[根 AGENTS.md](../../AGENTS.md)。

## 项目与代码入口

- 项目说明与资料导航见 [README.md](README.md)，各端目录、规范和历史差异见[三端开发说明](三端开发说明.md)。
- 需求任务通过 [prd/README.md](prd/README.md)定位实际版本，再按版本 README 和需求文档索引读取本次资料；发布任务读取本文件的发布约定和指定端发布记录。
- 各端代码仓库与本端规范入口统一见 [repos/README.md](repos/README.md)。

## 项目文档

- 版本入口见 [prd/README.md](prd/README.md)，模板选择与填写方法见[工作区模板说明](../../docs/requirements/README.md)。
- 归档方式与编号关联遵循[根文档组织约定](../../AGENTS.md#文档组织)；三端开发说明中的历史快照按[根依据与范围控制约定](../../AGENTS.md#依据与范围控制)使用。

## 发布记录

- 长期维护[发布记录iOS.md](发布记录iOS.md)、[发布记录Android.md](发布记录Android.md)、[发布记录HarmonyOS.md](发布记录HarmonyOS.md)，新发布版本放在最前面。
- 保持用户已确认的格式和文案，各版本只展示版本号、发布日期和逐条发布内容；不展示提交哈希、标签、分支、比较范围或核对过程。
- 使用简短通俗的业务语言，保留实际业务名称；不把内部调整扩写成新功能或未经证实的体验提升。
- 发布信息的确认与更新范围遵循[根文档组织约定](../../AGENTS.md#文档组织)。
- 现有历史日期口径保留：iOS、Android 暂按标签参考日期，附注标签取标签标记日期，轻量标签取关联提交日期；鸿蒙优先取同名 release 分支最后提交日期，无同名引用时暂用标签日期。统一按北京时间记录；此口径仅用于已有历史整理，用户明确更正时再更新。
