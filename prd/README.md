# 版本需求文档索引

各版本的产品需求及配套资料统一保存在本目录，路径为 `prd/prd-vxxx-YYYYMMDD/`。`xxx` 使用已确认的需求版本标识，日期使用该版本文件夹首次创建的日期。

同一版本后续补充、修改和验证继续维护原目录，不因日期变化重复创建。首次创建时登记目录链接、版本标识和创建日期；各端 App 的实际版本号与发布日期分别记录在根目录的三份发布记录中，不从某一端分支名推定需求版本或发布状态。

## 版本目录

暂无已登记版本。创建实际版本目录后在此添加索引。

## 每个版本的资料

```text
prd/
└── prd-vxxx-YYYYMMDD/
    ├── 00-文档索引.md
    ├── 01-产品需求.md
    ├── 02-技术方案.md
    ├── 03-开发任务.md
    ├── 04-AI测试用例.md
    ├── 05-人工测试验收.md
    └── sources/                  按需保存原始材料
```

内容按本次实际范围裁剪，填写职责、范围控制和写作要求见[模板使用说明](../docs/requirements/README.md)。本目录仅由根目录文档仓库记录本地提交，不上传任何远程。
