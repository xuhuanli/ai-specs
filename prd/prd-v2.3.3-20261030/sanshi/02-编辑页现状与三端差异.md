## 3 编辑页对照

| 场景 | iOS 当前实现 | Android 当前实现 | 鸿蒙现状／需求决定 |
| --- | --- | --- | --- |
| 新建入口 | 新建方式第一项进入编辑文章 | 同样进入 ArticleWriteFragment | 入口已有，尚未接页；本轮补此链路 |
| 旧文章编辑 | 模型回填标题与正文，详情分手机／电脑编辑 | 传 ArticleLibraryData 回填，原始换行转 br；详情按来源与 appSystem 区分入口 | 本次不顺带开放详情或旧文章入口，仅记录复用需求 |
| 标题上限 | 30；变化时截断并提示 | XML maxLength=50，最多 5 行 | 用户确认最多 30 字，不修改其他端 |
| 标题最小值 | title.length 大于 1，不 trim | isNullOrBlank，即非空白 | 用户确认有效非空，不沿用两字符门槛 |
| 正文校验 | 取得 HTML 并替换部分实体后检查 length；空或小于等于 10 被拦截，不能解释为可见正文至少 11 字 | 检查 HTML 字符串 isBlank，无可见字数门槛 | 用户确认有效正文非空，图片可算有效，排除空白和仅标签 |
| 富文本承载 | WKWebView＋定制 ZSSRichTextEditor，以 HTML 导入导出；默认格式工具条隐藏 | jp.wasabeef.richeditor 2.0.0，HTML 编辑 | 待实现，推荐本地 Web 图文编辑 |
| 格式工具 | 本页仅相机与图片；底层格式命令不代表页面开放对应按钮 | 本页仅绑定相机与图片，无加粗等按钮 | 按最新稿仅提供两个图标，不因底层能力扩大需求 |
| 标题与正文滚动 | 原生标题在 Web 正文上方，独立布局 | 原生标题在正文 WebView 上方 | 最新长文稿标题滚出视野，建议统一滚动；待交互确认 |
| 工具栏焦点 | 标题编辑时隐藏图片工具栏 | 标题获焦隐藏，正文获焦显示 | 建议正文编辑且键盘可见时显示 |
| 工具栏 UI | 两个等宽入口，图标＋相机／图片文字，48 高 | 两个等宽入口，图标＋文字，48dp 高 | 最新稿为靠左两个纯图标，不能照搬旧 UI |
| 相册数量 | 单次最多 9 张，禁止视频 | 单次最多 10 张，仅图片 | 通用 MediaUtils 当前固定单选；用户已确认本页单次最多 9 张，与 iOS 对齐，尚未实施 |
| 上传与插图 | 先上传，通过 base64 展示并映射远端 URL，导出时换 URL；拉选择器前保存选区 | 压缩上传后用文件 URL 插图，随后处理换行、滚动与焦点 | 需包含上传、光标位置、顺序与失败恢复，不能只加按钮 |
| 顶部保存 | 三选项：继续编辑、暂存草稿、直接发布 | 相同三个选择 | 用户已确认三选项，最新弹窗 UI 后补 |
| 草稿／发布 | create_doctor_article，is_send 0／1，分别提示保存成功／发布成功 | 同接口及标记；成功使用服务端 msg（有值时），刷新并返回 | 草稿已明确后台保存，成功提示后退出；发布细节待确认 |
| 返回未保存提示 | 本次在编辑控制器与相关组件未见专用未保存拦截 | 写文章页未覆写返回；基类虽有 backConfirm，但该页未调用 | Figma 新增退出确认框，不能声称两端已支持 |
| 成功返回 | 优先回文章列表，找不到则 pop 当前页 | 优先回文章列表，否则回医生主页，发 RefreshEvent | 建议当前新建成功回原列表，复用 onShown 静默刷新 |

两端仅作参考。富格式粘贴效果、输入法组合输入、选区与键盘行为未运行验证，不能由 WebView 或方法存在推定任意外部内容都能无损粘贴。

## 4 最新设计核对

[当前右侧 Figma](https://www.figma.com/design/aFKpQlzeW8NibL23OpY5lq/?node-id=21809-6127&p=f) 的手机上编辑组，可见四种编辑状态：空白新建、文字输入＋键盘、长文滚动＋键盘、文字与两张图片混排；下方另有退出确认框。三选项保存框不在本组已核对画面中，用户明确后补 UI。

长文图中导航保留、正文从中间段落开始、标题不可见，支持整体滚动的建议，但静态画面不能证明全部滚动规则。空态及图文无键盘画面未显示工具栏，正文键盘画面中两图标贴键盘上方。图片位于段落之间并适配内容宽度。

“最多显示30个字”原为设计示例文字；输入上限 30 的结论来自用户后续确认，依据分开。示例文章内容、截图缩放尺寸和系统键盘外观不作为业务约束。

插件因文件访问权限未读取成功，浏览器可查看设计但未取得节点标注和素材。相机、相册两枚图标需对应导出，不能认定其他端旧图或系统图标与新稿完全一致。
