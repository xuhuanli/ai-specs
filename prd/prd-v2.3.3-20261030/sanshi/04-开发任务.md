## 3 必要的实际适配

BaseWebClient 原先会把 resource://rawfile/ 判为未知协议，实际阻断文章本地文档。仅为该本地资源前缀补放行；https、file 和其他未知协议行为有回归覆盖，未替换通用容器。

ArkWeb 对 JS 字符串结果可能增加一层 JSON 封装，快照读取兼容两种返回形态；未将读取失败当空白文章。保存按钮使用 HPTScaffold.customRightAction 内的 HPTButton，因为当前导航默认文本按钮未使用 nameButtonHeight；图片栏避让通过本页 bottom safe-area 配置处理，不修改共享组件默认样式。

用户原有 AppScope/app.json5 改动保留，构建临时写入的版本字段已按开工快照恢复。保存弹框在快照读取前互斥，且不允许快速二次点击通过遮罩误关闭；设备双击保存已补验。

V2.3.3 是本需求版本；编译沿用现有 AgcDebug_Test 配置，不据测试包名称推定已发布 V2.3.3。
