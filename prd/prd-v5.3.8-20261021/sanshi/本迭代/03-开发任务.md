分享成功和复制范围分别见已关闭的 SAN-Q-006、007；客户端使用新 API 的方向见已关闭的 SAN-Q-008。埋点开发后置，不创建占位接口或新增复制功能。

编号和保险不再列入待提供清单：SAN-Q-001、002 及 SAN-DEP-001、002 均已关闭。预览隐藏编号、固定展示保险，不需要后台新增字段或接口。

### 开发阶段备注：SAN-NOTE-001

`usage_time`、`is_special_writing`、`auxiliaryNotify` 与 Android 的预览请求存在差异，详见技术方案第3.5节。用户要求先备注，开发涉及对应参数时再找用户确认，并据此更新处理逻辑和文档；不自动补传，不将其设为整个预览方案的开工前阻塞项。该备注不改变风险签名前置、取消失败保留预览或鸿蒙费用展示等已确认规则。
