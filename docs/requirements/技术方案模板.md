# 技术方案模板

通用流程、范围控制、写作、归档、验证与 Git 操作遵循[根 AGENTS.md](../../AGENTS.md)。本模板说明本类文档的填写内容。

开发主责填写，各端维护本端实现方案，后端确认接口与服务端能力；产品确认影响业务逻辑或交互的决定，测试核对可验证性。AI 可以协助追踪和起草，由对应开发负责人核对。

本文件填写当前实现、接口依赖、各端方案、风险与技术变更。
