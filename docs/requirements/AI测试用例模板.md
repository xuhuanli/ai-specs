# AI 测试用例模板

测试负责人维护覆盖范围、用例和预期，开发或自动化负责人补充运行工具与环境，AI 辅助生成并执行具备条件的用例。产品确认业务歧义；AI 不自行决定业务规则或把当前实现改写为预期。

这是面向 AI 执行者的测试规格，自动运行仍需相应工具、数据和测试实现。生成用例不代表已经执行。实际文件放入 `prd/prd-vxxx-YYYYMMDD/<姓名>/`，仅本地记录。

| --- | --- |
| 产品需求 | <链接、版本、确认日期或本地提交> |
| 技术方案与构建 | <方案版本、各端仓库提交及构建版本> |
| 测试负责人和执行者 | <人员；AI 执行方式> |
| 覆盖需求及验收 | <REQ、AC 编号及适用端> |
| 本轮执行范围 | <接口／单元／UI／设备等方法；按本次授权填写> |
| 不可执行或未覆盖范围 | <原因、对应 AC、转人工或补充验证安排> |
| 用例审核状态 | <待审核／已审核；人员与日期> |

业务预期引用产品需求中的 AC。断言指可自动判断的检查条件，可以补充实现验证，但不能替代 AC 要求的用户可见结果；模拟验证的结论只覆盖其实际范围。
