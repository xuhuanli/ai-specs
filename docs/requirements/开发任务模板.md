# 开发任务模板

通用流程、范围控制、写作、归档、验证与 Git 操作遵循[根 AGENTS.md](../../AGENTS.md)。本模板说明本类文档的填写内容。

开发负责人组织拆分，各端开发维护自己的任务和交付状态，后端维护其依赖任务。测试补充提测及验证依赖，产品确认范围和优先级变化。AI 可生成草稿，负责人核对范围与依赖。

本文件填写任务拆分、依赖、完成判据和各端交付状态，关联产品需求与技术方案。
