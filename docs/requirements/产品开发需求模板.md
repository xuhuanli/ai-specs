# 产品开发需求模板

本文件由产品主责填写，用于确认 iOS、Android、鸿蒙共同的业务逻辑和交互。设计补充设计稿与交互标注；开发核对当前能力和可行性；测试检查规则是否清楚、预期是否可判断。业务规则和交互预期由产品或明确的业务决策人确认。

技术方案、开发任务、AI 测试用例、人工测试验收分别放入配套文档。本文件保留简短的业务验收标准，作为配套文档共同使用的判断依据。

实际版本资料存放在 `prd/prd-vxxx-YYYYMMDD/<姓名>/`，只进入根目录文档仓库的本地提交，不上传任何远程。职责和文档组织见[使用说明](README.md)。所有尖括号内容均为占位符；不适用项说明原因，未知项登记问题。
