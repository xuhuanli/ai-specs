# 人工测试验收模板

通用流程、范围控制、写作、归档、验证与 Git 操作遵循[根 AGENTS.md](../../AGENTS.md)。本模板说明本类文档的填写内容。

测试人员主责填写测试准备、可操作用例、缺陷和测试结论；开发提供构建、环境和数据准备能力；产品确认业务规则、交互预期与最终业务验收。AI 可以起草和查漏，测试人员审核后使用。

本文件填写测试准备、可操作步骤、预期表现、缺陷和人工执行记录。
