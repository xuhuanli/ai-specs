# 人工测试验收模板

测试人员主责填写测试准备、可操作用例、缺陷和测试结论；开发提供构建、环境和数据准备能力；产品确认业务规则、交互预期与最终业务验收。AI 可以起草和查漏，测试人员审核后使用。

本文件面向测试人员，操作步骤和预期应能直接理解。业务预期统一引用产品需求的 REQ 和 AC；与 AI 用例共用同一份已确认的需求版本，执行结果独立记录。实际文件放入 `prd/prd-vxxx-YYYYMMDD/<姓名>/`，仅本地记录。
